# Preguntas frecuentes reales

Mine the questions clients ACTUALLY ask, from INBOUND messages only — not the
questions the business thinks it gets.

Look for:
- Recurring question intents (price, stock, shipping, payment, specs, hours,
  location, warranty...). Group by intent, not by exact wording.
- The exact phrasing clients use — quote them verbatim; those phrasings are
  gold for FAQ pages and bot intents.
- Questions that repeatedly receive the same templated answer (automation
  candidates) vs questions that get long custom answers (knowledge that lives
  only in the operator's head).
- Questions that never get answered at all.

Count honestly: an intent seen once is an anecdote, not a frequent question.
State the actual number of distinct threads where each intent appears.

Suggested row columns: question intent, verbatim example, distinct threads
where it appears, how it is answered today.
