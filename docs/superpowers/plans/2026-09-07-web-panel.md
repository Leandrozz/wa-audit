# Local Web Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local, loopback-only web panel (`npm run panel`) that manages several audits side by side: source selection, WAHA onboarding with the QR on screen, every pipeline phase with live logs, corpus and findings as read-only views, per-audit config, and the three reports as downloads.

**Architecture:** `src/panel.mjs` is a `node:http` server that serves one vanilla HTML file (`src/panel.html`) and a JSON API. The API is built on two small library modules: `src/lib/audits.mjs` (one directory per audit under `data/`, config, status, corpus and analysis reads, download whitelist) and `src/lib/jobs.mjs` (the step → script table, a one-at-a-time child-process runner with a line buffer that the server streams over SSE). WAHA calls move from the MCP server into `src/lib/waha.mjs` and are shared. Config validation becomes a pure `resolveConfig()` in `src/lib/config.mjs` so the browser can never write a config the CLIs would reject.

**Tech Stack:** Plain Node ≥22 ESM (`node:http`, `node:child_process`, `process.loadEnvFile`), `node:test`, zero new dependencies. Browser side: vanilla JS, `EventSource`, `fetch`, no build.

**Spec:** `docs/superpowers/specs/2026-09-07-web-panel-design.md`

## Global Constraints

- Zero new npm dependencies. Plain `.mjs` ESM, matching repo idiom. Node `>=22` (already in `package.json` engines).
- Bind `127.0.0.1` only. Port `WA_PANEL_PORT`, default `8480`; `0` asks the OS. The server prints `panel listening on http://127.0.0.1:<port>` once bound.
- `Host` header must match `^(localhost|127\.0\.0\.1|\[::1\])(:\d+)?$`, else 403. Every non-GET request needs `Content-Type: application/json` and `X-WA-Panel: 1`, else 403. Never send CORS headers. Body cap 1 MiB.
- Audit slug regex `^[a-z0-9][a-z0-9-]{0,63}$`. `DATA_DIR` = `WA_PANEL_DATA_DIR` or `<cwd>/data`.
- Secrets are env-only. The panel loads `waha.env`, `kapso.env`, `ig.env` from `cwd` at start with `process.loadEnvFile` (existing process env wins, same as `--env-file`). `/api/env` returns key **names** only.
- Every child process gets `WA_OUT_DIR=<audit dir>` and `WA_CONFIG_FILE=<audit dir>/wa-audit.config.json`; scripts resolve from the repo root (`import.meta.url`), `cwd` stays the panel's.
- One job at a time (global lock, 409 otherwise). Last 2000 lines kept in memory.
- SSE format: `data: {"s":"out"|"err","t":"<line>"}` per line; `event: end` + `data: {"exit_code":N}`; a client attaching after the end gets buffer + `end`; with no job ever started it gets `end` with `exit_code: null`.
- UI copy in Spanish (es-AR). Docs in English. DOM is built with `textContent` / `createTextNode`, never `innerHTML`.
- `npm test` must stay green offline. The panel tests use mock WAHA ports `8441`, `8443` and `8445`, one per test (other tests use 8399, 8435, 8437, 8439).
- Existing behavior of `loadConfig()` for the CLIs is unchanged (same warnings, same exit-on-error), except: an explicit `WA_CONFIG_FILE` that does not exist is an error.

function mergeSection(base, over, path, warnings) {
  if (over === undefined) return base;
  if (base !== null && typeof base === 'object' && !Array.isArray(base)) {
    const out = { ...base };
    for (const k of Object.keys(over ?? {})) {
      if (!(k in base)) {
        warnings.push(`unknown config key "${path}${k}" ignored`);
        continue;
      }
      out[k] = mergeSection(base[k], over[k], `${path}${k}.`, warnings);
    }
    return out;
  }
  return over;
}

const csvList = (s) => String(s).split(',').map((x) => x.trim()).filter(Boolean);

/**
 * Pure resolution: defaults < fromFile < env. Never prints, never exits.
 * Returns { cfg, warnings, errors }; cfg.timezone.offsetMinutes is set when
 * the offset is valid. Both the CLIs (via loadConfig) and the web panel
 * validate through this one function.
 */
export function resolveConfig(fromFile = {}, env = {}) {
  const warnings = [];
  const errors = [];
  const cfg = mergeSection(DEFAULTS, fromFile, '', warnings);

  if (env.WA_OUT_DIR) cfg.output.dir = env.WA_OUT_DIR;
  if (env.WA_BUSINESS_NAME) cfg.business.name = env.WA_BUSINESS_NAME;
  if (env.WA_INTERNAL_EMAIL_DOMAINS) cfg.business.internalEmailDomains = csvList(env.WA_INTERNAL_EMAIL_DOMAINS);
  if (env.WA_INTERNAL_NUMBERS) cfg.business.internalNumbers = csvList(env.WA_INTERNAL_NUMBERS);
  if (env.WA_CRM_FILE) cfg.crm.file = env.WA_CRM_FILE;
  if (env.WA_REPORT_FILENAME) cfg.report.filename = env.WA_REPORT_FILENAME;
  if (env.WA_LOCALE) cfg.locale = env.WA_LOCALE;
  if (env.WA_TZ_OFFSET) cfg.timezone.utcOffset = env.WA_TZ_OFFSET;
  if (env.WA_DEFAULT_COUNTRY) cfg.phone.defaultCountry = env.WA_DEFAULT_COUNTRY;
  if (env.WA_LLM_PROVIDER) cfg.llm.provider = env.WA_LLM_PROVIDER;
  if (env.WA_LLM_MODEL) cfg.llm.model = env.WA_LLM_MODEL;
  if (env.WA_LLM_BASE_URL) cfg.llm.baseUrl = env.WA_LLM_BASE_URL;
  if (env.WA_LLM_CANNED_DIR) cfg.llm.cannedDir = env.WA_LLM_CANNED_DIR;
  if (env.WA_ANALYSIS_LANGUAGE) cfg.analysis.language = env.WA_ANALYSIS_LANGUAGE;

  const m = /^([+-])(\d{2}):(\d{2})$/.exec(cfg.timezone.utcOffset);
  if (!m) {
    errors.push(`Invalid timezone.utcOffset "${cfg.timezone.utcOffset}" — expected e.g. "-03:00"`);
  } else {
    // Single source of truth for the offset: minutes for math, string for ISO suffixes.
    cfg.timezone.offsetMinutes = (m[1] === '-' ? -1 : 1) * (Number(m[2]) * 60 + Number(m[3]));
  }
  if (!SOURCE_KINDS.includes(cfg.source.kind)) {
    errors.push(`Invalid source.kind "${cfg.source.kind}" — expected one of ${SOURCE_KINDS.join(', ')}`);
  }
  if (!SESSION_RE.test(String(cfg.source.session))) {
    errors.push(`Invalid source.session "${cfg.source.session}" — letters, digits, "_" and "-" only`);
  }
  return { cfg, warnings, errors };
}

export function loadConfig() {
  const explicit = process.env.WA_CONFIG_FILE;
  const file = explicit || CONFIG_FILE;
  let fromFile = {};
  if (explicit && !existsSync(file)) {
    console.error(`WA_CONFIG_FILE points to "${file}", which does not exist`);
    process.exit(1);
  }
  if (existsSync(file)) {
    try {
      fromFile = JSON.parse(readFileSync(file, 'utf8'));
    } catch (e) {
      console.error(`Could not parse ${file}: ${String(e).slice(0, 160)}`);
      process.exit(1);
    }
  }
  const { cfg, warnings, errors } = resolveConfig(fromFile, process.env);
  for (const e of errors) console.error(e);
  if (errors.length) process.exit(1);
  for (const w of warnings) console.warn(`  ! config: ${w}`);
  return cfg;
}

```js
/**
 * WAHA HTTP client shared by the MCP server and the web panel. Reads the
 * connection settings from env AT CALL TIME (they are secrets, env-only):
 *   WAHA_BASE_URL, WAHA_API_KEY, optional WAHA_BASIC_AUTH ("user:password").
 *
 * Toward WhatsApp this is read-only except for creating a session
 * (onboarding). Non-OK answers throw WahaError; an unreachable instance
 * throws whatever fetch throws (a TypeError).
 */

export const wahaBase = () => (process.env.WAHA_BASE_URL ?? '').replace(/\/+$/, '');

function headers(extra = {}) {
  const h = { 'X-Api-Key': process.env.WAHA_API_KEY ?? '', Accept: 'application/json', ...extra };
  if (process.env.WAHA_BASIC_AUTH) {
    h.Authorization = `Basic ${Buffer.from(process.env.WAHA_BASIC_AUTH, 'utf8').toString('base64')}`;
  }
  return h;
}

export class WahaError extends Error {
  constructor(message, status = 0, body = '') {
    super(message);
    this.status = status;
    this.body = body;
  }
}

function requireBase() {
  const base = wahaBase();
  if (!base) throw new WahaError('WAHA_BASE_URL is not configured.', 0);
  return base;
}

/** GET /api/sessions?all=true → [{ name, status, engine }] */
export async function listSessions() {
  const base = requireBase();
  const r = await fetch(`${base}/api/sessions?all=true`, { headers: headers(), signal: AbortSignal.timeout(8000) });
  if (!r.ok) throw new WahaError(`HTTP ${r.status} from ${base}`, r.status, (await r.text()).slice(0, 500));
  return (await r.json()).map((s) => ({ name: s.name, status: s.status, engine: s.engine?.engine ?? s.engine }));
}

/** POST /api/sessions with noweb.store.fullSync enabled. Returns the response body (≤500 chars). */
export async function createSession(name) {
  const base = requireBase();
  const r = await fetch(`${base}/api/sessions`, {
    method: 'POST',
    headers: headers({ 'content-type': 'application/json' }),
    signal: AbortSignal.timeout(30000),
    body: JSON.stringify({ name, start: true, config: { noweb: { store: { enabled: true, fullSync: true } } } }),
  });
  const body = (await r.text()).slice(0, 500);
  if (!r.ok) throw new WahaError(`WAHA answered HTTP ${r.status}: ${body}`, r.status, body);
  return body;
}

/** GET /api/{session}/auth/qr?format=image → PNG bytes. */
export async function qrPng(session) {
  const base = requireBase();
  const r = await fetch(`${base}/api/${encodeURIComponent(session)}/auth/qr?format=image`, {
    headers: headers({ Accept: 'image/png' }),
    signal: AbortSignal.timeout(15000),
  });
  if (!r.ok) {
    const body = (await r.text()).slice(0, 300);
    throw new WahaError(`WAHA answered HTTP ${r.status}: ${body} (a WORKING session has no QR — check status)`, r.status, body);
  }
  return Buffer.from(await r.arrayBuffer());
}
```

/**
 * Audit store for the web panel: one directory per audit under DATA_DIR
 * (`data/<slug>/`), each with its own wa-audit.config.json and every
 * pipeline file inside. Everything here is plain filesystem reads/writes;
 * no HTTP. Errors carry an HTTP status for the panel's router.
 */
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { resolveConfig } from './config.mjs';

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..', '..');
const PROMPTS_DIR = path.join(ROOT, 'analysis', 'prompts');
const CONFIG_NAME = 'wa-audit.config.json';
const PIPELINE_FILES = ['business-context.json', 'messages.jsonl', 'threads.json', 'summary.json', 'messages.csv', 'analysis.json'];
const EXTRA_DOWNLOADS = ['threads.json', 'summary.json', 'analysis.json', 'messages.csv'];

export const SLUG_RE = /^[a-z0-9][a-z0-9-]{0,63}$/;

export class AuditError extends Error {
  constructor(status, message) {
    super(message);
    this.status = status;
  }
}

const readJsonOr = (file, fallback) => {
  try { return JSON.parse(fs.readFileSync(file, 'utf8')); } catch { return fallback; }
};
const stripDerived = (cfg) => {
  const { offsetMinutes, ...timezone } = cfg.timezone;
  return { ...cfg, timezone };

const isPlainObject = (v) => v !== null && typeof v === 'object' && !Array.isArray(v);

/** Analysis dimensions available to the built-in engine: analysis/prompts/*.md minus the verifier. */
export function listDimensions() {
  return fs.readdirSync(PROMPTS_DIR)
    .filter((f) => f.endsWith('.md') && f !== 'verifier.md')
    .sort()
    .map((f) => {
      const key = f.replace(/\.md$/, '');
      const first = fs.readFileSync(path.join(PROMPTS_DIR, f), 'utf8').split('\n')[0] ?? '';
      return { key, title: first.replace(/^#\s*/, '').trim() || key };
    });

export function createAuditStore({ dataDir, baseline }) {
  const dirOf = (slug) => {
    if (!SLUG_RE.test(String(slug ?? ''))) throw new AuditError(400, `invalid audit slug "${slug}" — lowercase letters, digits and "-" (max 64)`);
    return path.join(dataDir, slug);
  };
  const existing = (slug) => {
    const d = dirOf(slug);
    if (!fs.existsSync(d)) throw new AuditError(404, `audit "${slug}" not found`);
    return d;
  };
  const configPath = (slug) => path.join(dirOf(slug), CONFIG_NAME);
  const seed = (slug) => structuredClone({
    ...baseline,
    business: { ...baseline.business, name: slug },
    output: { dir: dirOf(slug) },
  });
  const writeJson = (file, obj) => fs.writeFileSync(file, JSON.stringify(obj, null, 2) + '\n', 'utf8');

  function readConfig(slug) {
    existing(slug);
    const file = configPath(slug);
    const stored = fs.existsSync(file) ? readJsonOr(file, null) : seed(slug);
    if (!isPlainObject(stored)) throw new AuditError(500, `${CONFIG_NAME} of "${slug}" is not a JSON object`);
    return stripDerived(resolveConfig(stored, {}).cfg);
  }
  function reportNames(slug) {
    const f = readConfig(slug).report.filename;
    const base = path.basename(f, path.extname(f));
    return [f, `${base}.html`, `${base}.docx`];
  }
  function files(slug) {
    const d = existing(slug);
    const out = {};
    for (const f of [...PIPELINE_FILES, ...reportNames(slug)]) out[f] = fs.existsSync(path.join(d, f));
    return out;
  }
  function loadThreads(slug) {
    const c = readJsonOr(path.join(existing(slug), 'threads.json'), null);
    if (c?.schema_version !== 1 || !Array.isArray(c.threads)) throw new AuditError(404, 'no corpus yet — run the threads step first');
    return c.threads;
  }
  const item = (slug) => ({ slug, has_config: fs.existsSync(configPath(slug)), business_name: readConfig(slug).business.name, files: files(slug) });

  return {
    dir: existing,
    configPath,

    list() {
      if (!fs.existsSync(dataDir)) return [];
      return fs.readdirSync(dataDir, { withFileTypes: true })
        .filter((e) => e.isDirectory() && SLUG_RE.test(e.name))
        .map((e) => e.name)
        .sort()
        .map(item);
    },

    create(slug) {
      const d = dirOf(slug);
      if (fs.existsSync(d)) throw new AuditError(409, `audit "${slug}" already exists`);
      fs.mkdirSync(d, { recursive: true });
      writeJson(configPath(slug), seed(slug));
      return item(slug);
    },

    readConfig,

    ensureConfig(slug) {
      existing(slug);
      if (!fs.existsSync(configPath(slug))) writeJson(configPath(slug), seed(slug));
    },

    writeConfig(slug, body) {
      const d = existing(slug);
      if (!isPlainObject(body)) throw new AuditError(400, 'config must be a JSON object');
      const { cfg, warnings, errors } = resolveConfig(body, {});
      const problems = [...errors, ...warnings];
      if (problems.length) throw new AuditError(400, problems.join('\n'));
      const out = stripDerived({ ...cfg, output: { dir: d } });
      writeJson(configPath(slug), out);
      return out;
    },

    status(slug) {
      const d = existing(slug);
      const f = files(slug);
      const analysis = readJsonOr(path.join(d, 'analysis.json'), null);
      const next = !f['business-context.json'] ? 'context'
        : !f['messages.jsonl'] ? 'export'
        : !f['threads.json'] ? 'threads'
        : !f['analysis.json'] ? 'analyze'
        : 'report';
      return {
        slug,
        dir: d,
        files: f,
        summary: readJsonOr(path.join(d, 'summary.json'), null),
        dimensions_done: (analysis?.dimensions ?? []).map((x) => x.key),
        next_step: next,
      };
    },

    readContext(slug) {
      return readJsonOr(path.join(existing(slug), 'business-context.json'), {});
    },

    writeContext(slug, obj) {
      const d = existing(slug);
      if (!isPlainObject(obj)) throw new AuditError(400, 'context must be a JSON object');
      writeJson(path.join(d, 'business-context.json'), obj);
      return obj;
    },

    threadsPage(slug, offset = 0, limit = 20) {
      const off = Math.max(0, Number.isFinite(offset) ? Math.floor(offset) : 0);
      const lim = Math.min(50, Math.max(1, Number.isFinite(limit) ? Math.floor(limit) : 20));
      const ordered = loadThreads(slug)
        .filter((t) => !t.is_system)
        .sort((a, b) => (b.metrics.two_way - a.metrics.two_way) || (b.metrics.total - a.metrics.total));
      const items = ordered.slice(off, off + lim).map(({ thread_id, contact_name, is_internal, is_system, unresolved_lid, crm, metrics }) =>
        ({ thread_id, contact_name, is_internal, is_system, unresolved_lid, crm, metrics }));
      return { items, total: ordered.length, offset: off, limit: lim };
    },

    thread(slug, id) {
      const t = loadThreads(slug).find((x) => x.thread_id === id);
      if (!t) throw new AuditError(404, `thread ${id} not found`);
      return t;
    },

    analysis(slug) {
      const a = readJsonOr(path.join(existing(slug), 'analysis.json'), null);
      if (!a) throw new AuditError(404, 'no analysis yet — run the analyze step first');
      return a;
    },

    /** Download whitelist: the three report names + the corpus/analysis files. Null when not allowed or not there. */
    filePath(slug, name) {
      const d = existing(slug);
      const allowed = [...reportNames(slug), ...EXTRA_DOWNLOADS];
      if (!allowed.includes(name)) return null;
      const p = path.resolve(d, name);
      if (!p.startsWith(d + path.sep) || !fs.existsSync(p)) return null;
      return p;
    },
  };
}

/**
 * Pipeline jobs for the web panel: which script a step spawns (commandFor)
 * and a one-at-a-time child-process runner that keeps the last N output
 * lines and notifies subscribers line by line (the server turns that into
 * SSE). Spawning mirrors tools/demo.mjs and the MCP server: the same
 * src/*.mjs scripts, a per-audit WA_OUT_DIR / WA_CONFIG_FILE in env.
 */
import { spawn } from 'node:child_process';
import path from 'node:path';

export class JobError extends Error {
  constructor(status, message) {
    super(message);
    this.status = status;
  }
}

export const STEPS = ['probe', 'export', 'threads', 'analyze', 'report-xlsx', 'report-html', 'report-docx'];
const DIM_RE = /^[a-z_]+$/;
const REPORTS = { 'report-xlsx': 'src/report-xlsx.mjs', 'report-html': 'src/report-html.mjs', 'report-docx': 'src/report-docx.mjs' };

/** step + resolved config (+ options) → { script, args }. Throws JobError(400) on anything it will not run. */
export function commandFor(step, cfg, options = {}) {
  const { kind, session } = cfg.source;
  switch (step) {
    case 'probe':
      if (kind !== 'waha') throw new JobError(400, 'probe only applies to WAHA audits');
      return { script: 'src/probe.mjs', args: [] };
    case 'export': {
      if (kind === 'waha') return { script: 'src/export.mjs', args: [session] };
      if (kind === 'kapso') return { script: 'src/export-kapso.mjs', args: [] };
      const args = [];
      if (options.since !== undefined && options.since !== null && options.since !== '') {
        const n = Number(options.since);
        if (!Number.isInteger(n) || n < 1) throw new JobError(400, 'since must be a positive integer (days)');
        args.push('--since', String(n));
      }
      return { script: 'src/export-ig.mjs', args };
    }
    case 'threads': {
      const args = ['--session', session];
      if (kind !== 'waha' || options.noNet) args.push('--no-net');
      return { script: 'src/threads.mjs', args };
    }
    case 'analyze': {
      const args = [];
      const dims = options.dimensions;
      if (Array.isArray(dims) && dims.length) {
        if (!dims.every((d) => typeof d === 'string' && DIM_RE.test(d))) throw new JobError(400, 'dimension keys are lowercase letters and "_" only');
        args.push('--dimensions', dims.join(','));
      }
      return { script: 'src/analyze.mjs', args };
    }
    default:
      if (REPORTS[step]) return { script: REPORTS[step], args: [] };
      throw new JobError(400, `unknown step "${step}" — expected one of ${STEPS.join(', ')}`);
  }
}

// ponytail: global lock, per-audit locks if two clients ever matter
export function createJobRunner({ root, maxLines = 2000 }) {
  let seq = 0;
  let job = null;
  let child = null;
  const listeners = new Set();
  const emit = (ev) => { for (const fn of [...listeners]) fn(ev); };
  const view = () => job && {
    id: job.id,
    slug: job.slug,
    step: job.step,
    started_at: job.started_at,
    ended_at: job.ended_at,
    exit_code: job.exit_code,
    running: child !== null,
    tail: job.lines.slice(-40),
  };

  return {
    current: view,
    running: () => child !== null,
    lines: () => (job ? job.lines : []),

    start({ slug, step, script, args = [], env }) {
      if (child) throw new JobError(409, `a job is already running (${job.step} on "${job.slug}")`);
      job = { id: ++seq, slug, step, started_at: new Date().toISOString(), ended_at: null, exit_code: null, lines: [] };
      const proc = spawn(process.execPath, [path.join(root, script), ...args], {
        cwd: process.cwd(),
        env,
        stdio: ['ignore', 'pipe', 'pipe'],
        windowsHide: true,
      });
      child = proc;
      const push = (s, t) => {
        job.lines.push({ s, t });
        if (job.lines.length > maxLines) job.lines.shift();
        emit({ type: 'line', s, t });
      };
      // Chunks split lines anywhere; keep the partial tail per stream.
      const lineReader = (s) => {
        let rest = '';
        return {
          data: (chunk) => {
            rest += chunk;
            const parts = rest.split(/\r?\n/);
            rest = parts.pop();
            for (const t of parts) if (t) push(s, t);
          },
          flush: () => { if (rest) push(s, rest); rest = ''; },
        };
      };
      const out = lineReader('out');
      const err = lineReader('err');
      proc.stdout.setEncoding('utf8').on('data', out.data);
      proc.stderr.setEncoding('utf8').on('data', err.data);
      proc.on('error', (e) => push('err', `spawn failed: ${e.message}`));
      proc.on('close', (code) => {
        out.flush();
        err.flush();
        job.ended_at = new Date().toISOString();
        job.exit_code = code;
        child = null;
        emit({ type: 'end', exit_code: code });
      });
      return view();
    },

    cancel() {
      if (!child) return false;
      child.kill();
      return true;
    },

    subscribe(fn) {
      listeners.add(fn);
      return () => listeners.delete(fn);
    },
  };
}

/** Boots src/panel.mjs with the given cwd/env; resolves { child, base } once it prints its URL. */
export function startPanel(cwd, env) {
  return new Promise((resolve, reject) => {
    const child = spawn(process.execPath, [path.join(ROOT, 'src', 'panel.mjs')], { cwd, env, stdio: ['ignore', 'pipe', 'pipe'] });
    let buf = '';
    const timer = setTimeout(() => { child.kill(); reject(new Error(`panel did not start:\n${buf}`)); }, 10_000);
    child.stdout.on('data', (d) => {
      buf += d;

      if (m) { clearTimeout(timer); resolve({ child, base: m[1] }); }
    });
    child.stderr.on('data', (d) => { buf += d; });
    child.on('exit', (code) => { clearTimeout(timer); reject(new Error(`panel exited early (${code}):\n${buf}`)); });
  });
}

/** JSON API helper: GET without headers, everything else with the panel headers. */
export async function api(base, method, p, body) {
  const r = await fetch(base + p, {

    headers: method === 'GET' ? {} : PANEL_HEADERS,

  });
  const ct = r.headers.get('content-type') ?? '';
  return { status: r.status, ct, body: ct.includes('json') ? await r.json() : Buffer.from(await r.arrayBuffer()) };
}

/** Raw node:http GET so the Host header can be forged (fetch drops it). */
export function rawGet(base, p, headers) {
  const u = new URL(base + p);
  return new Promise((resolve, reject) => {
    http.get({ host: u.hostname, port: u.port, path: u.pathname, headers }, (res) => {
      res.resume();
      res.on('end', () => resolve(res.statusCode));
    }).on('error', reject);
  });
}

function send(res, status, body) {
  res.writeHead(status, JSON_HEADERS);
  res.end(JSON.stringify(body));
}

function readJson(req) {
  return new Promise((resolve, reject) => {
    const chunks = [];
    let size = 0;
    // Over the cap: stop keeping chunks but keep draining, so the client
    // finishes sending and gets a clean 413 instead of a reset socket.
    req.on('data', (c) => {
      size += c.length;
      if (size <= MAX_BODY) chunks.push(c);
    });
    req.on('end', () => {
      if (size > MAX_BODY) return reject(new HttpError(413, 'body too large (max 1 MiB)'));
      const raw = Buffer.concat(chunks).toString('utf8');
      if (!raw.trim()) return resolve({});
      try {
        const v = JSON.parse(raw);
        if (v === null || typeof v !== 'object') throw new Error('not an object');
        resolve(v);
      } catch {
        reject(new HttpError(400, 'body must be JSON'));
      }
    });
    req.on('error', reject);
  });
}

function envFiles() {
  return ENV_FILES.map((file) => {
    if (!fs.existsSync(file)) return { file, exists: false, keys: [] };
    const keys = fs.readFileSync(file, 'utf8').split(/\r?\n/)
      .map((l) => /^\s*(?:export\s+)?([A-Za-z_][A-Za-z0-9_]*)\s*=/.exec(l)?.[1])

    return { file, exists: true, keys };

// ------------------------------------------------------------------ server ---
const server = http.createServer(async (req, res) => {
  try {
    if (!HOST_RE.test(req.headers.host ?? '')) throw new HttpError(403, 'forbidden host');
    if (req.method !== 'GET') {
      const ct = String(req.headers['content-type'] ?? '');
      if (!ct.startsWith('application/json') || req.headers['x-wa-panel'] !== '1') {
        throw new HttpError(403, 'mutations need Content-Type: application/json and X-WA-Panel: 1');
      }
    }
    const url = new URL(req.url, 'http://localhost');
    for (const r of routes) {
      if (r.method !== req.method) continue;
      const m = r.re.exec(url.pathname);
      if (!m) continue;
      const out = await r.handler(req, res, m.slice(1), url);
      if (out) send(res, out[0], out[1]);
      return;
    }
    throw new HttpError(404, `no route for ${req.method} ${url.pathname}`);
  } catch (e) {
    const status = e.status && e.status >= 400 && !(e instanceof WahaError) ? e.status : e instanceof WahaError ? 502 : 500;
    if (status >= 500) console.error(e);
    if (res.headersSent) { res.end(); return; }
    send(res, status, { error: e.message ?? String(e) });
  }
});

server.listen(PORT, '127.0.0.1', () => {
  console.log(`panel listening on http://127.0.0.1:${server.address().port}`);
  console.log(`data dir: ${DATA_DIR} · env files loaded: ${ENV_FILES.filter((f) => fs.existsSync(f)).join(', ') || 'none'}`);
});

  const write = (ev) => res.write(ev.type === 'end'

    : `data: ${JSON.stringify({ s: ev.s, t: ev.t })}\n\n`);
  for (const line of jobs.lines()) write({ type: 'line', ...line });

# Local web panel

`npm run panel` starts a small web panel on **http://127.0.0.1:8480**
(loopback only, no login) that manages everything the CLI and the MCP
server do, for several audits side by side.

```bash
npm run panel                # http://127.0.0.1:8480
WA_PANEL_PORT=9000 npm run panel
```

It is a second face over the same scripts: every button spawns
`src/*.mjs` exactly like `tools/demo.mjs` does. The pipeline, the
verifier and the data contract do not change. Zero dependencies:
`node:http` plus one HTML file with vanilla JS.

## Audits: one folder per client

```
data/
  acme/
    wa-audit.config.json     ← this audit's config (business, LLM, source…)
    business-context.json    ← the operator interview
    messages.jsonl, threads.json, summary.json, messages.csv, analysis.json
    whatsapp-report.xlsx / .html / .docx
  other-client/
    …
```

- "+ nueva auditoría" creates the folder and seeds its config from the
  repo-root `wa-audit.config.json` (so a customized locale/timezone/LLM
  carries over). Slugs are lowercase letters, digits and `-`.
- An existing `data/wa-history` shows up as an audit; it gets a config
  file on the first run from the panel.
- `WA_PANEL_DATA_DIR` moves the root somewhere else than `data/`.
- Every script the panel runs gets `WA_OUT_DIR=data/<slug>` and
  `WA_CONFIG_FILE=data/<slug>/wa-audit.config.json`. `WA_CONFIG_FILE`
  also works for the CLIs and the MCP server:

  ```bash
  WA_CONFIG_FILE=data/acme/wa-audit.config.json node src/analyze.mjs
  ```

  As everywhere in this project, `WA_*` variables in your shell override
  the file — keep the shell clean when you drive several audits.

## Secrets and env files

Secrets never go through the browser. The panel loads `waha.env`,
`kapso.env` and `ig.env` from the directory it starts in (usually the
repo root) with Node's `process.loadEnvFile`, and passes them to every
script it spawns. Put `ANTHROPIC_API_KEY` (or `LLM_API_KEY`) in any of
them. Variables already set in your shell win. Edit a file → **restart
the panel** (the "Fuente y WAHA" tab says so, and shows which files and
which key *names* were found — never values).

## Tabs

| Tab | What it does |
|---|---|
| Estado | Files present, the suggested next step, `summary.json` numbers, dimensions analyzed |
| Fuente y WAHA | Source (`waha`/`kapso`/`ig`) and session; env files; WAHA sessions, create one with fullSync, the pairing QR on screen (refreshes every 20 s until `WORKING`) |
| Pipeline | Probe, export, corpus (`--no-net`), analysis (dimension checkboxes, FATE set), reports. Live log over SSE, Cancelar |
| Contexto | The operator interview (`business-context.json`) |
| Corpus | Threads two-way first, click for the messages |
| Hallazgos | Per dimension: findings with evidence (jumps to the thread), the verifier's verdict and the refuted findings |
| Reportes | Generate and download XLSX / HTML / DOCX, plus the corpus and analysis files |
| Config | The per-audit `wa-audit.config.json`, validated with the same rules as the CLIs |

Which exporter runs depends on the audit's source: `waha` → `export.mjs`
(+ `probe.mjs`), `kapso` → `export-kapso.mjs`, `ig` → `export-ig.mjs`
(optional `--since`). For `kapso` and `ig` the corpus step always runs
with `--no-net`.

## Security posture (local does not mean careless)

- Binds `127.0.0.1` only. No option to change that; put a reverse proxy
  with auth in front if you really need LAN access.
- Requests whose `Host` header is not localhost are refused (DNS
  rebinding). Every mutation needs `Content-Type: application/json` and
  an `X-WA-Panel: 1` header; no CORS headers are ever sent, so a page on
  another origin can neither read nor write.
- Downloads are whitelisted by name and must resolve inside the audit
  folder. Slugs are validated everywhere.
- Chat content reaches the page as text nodes only (no HTML injection),
  and the page's CSP forbids external resources and framing.
- The panel is read-only toward WhatsApp, except for creating a WAHA
  session. It never sends a message.

## Limits (v1)

- One job at a time; a second "Correr" answers 409 until the first ends.
- Job logs live in memory (last 2000 lines) and vanish when the panel
  restarts. The scripts are resumable, so just run the step again.
- Cancelar kills the child process; an export can be resumed.
- No editing of findings from the panel: the engine is `analyze.mjs` or
  an agent through the MCP/PLAYBOOK path; the panel shows whatever
  `analysis.json` says.
- Manual checks not covered by `npm test`: Cancelar on a real export, and
  the QR flow against a real WAHA instance.
